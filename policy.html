Policy & Governance

Data Policy

Privacy

Card Block API does not collect any personal information. All data is:

  • Publicly available from official bank sources
  • Stored locally in your browser (no server tracking)
  • Free to access without registration

Data Sources

All information is sourced from:

  • Official bank websites
  • RBI disclosures and guidelines
  • Verified customer communications
  • Community contributions (pending verification)

Verification Policy

We use a multi-tier verification system:

🤖 Agent Verified

AI-verified through official sources. High confidence (70%+).

✅ Human Verified

Manually verified by contributors. Highest confidence.

👤 Community Reported

Submitted by users, pending verification.

❓ Unverified

Information added but not yet verified.

Contribution Guidelines

We welcome contributions! Here's how:

Adding New Banks

  1. Fork the repository
  2. Add bank data in JSON format
  3. Include official sources for all information
  4. Submit pull request

Reporting Errors

Found outdated information?

  • Open an issue on GitHub
  • Include correct information and source
  • Our AI agents will verify and update

Disclaimer

Important: While we strive for accuracy, Card Block API provides information "as is". Always verify with your bank before taking action.

We are not responsible for any actions taken based on this information. Contact your bank directly for official blocking procedures.

RBI Compliance

This project supports RBI guidelines requiring banks to provide:

  • Multiple channels for card blocking (SMS, phone, app, website)
  • 24/7 availability for emergency blocking
  • Clear information on card blocking procedures
  • Temporary freeze options

We help consumers exercise their right to control their cards.
